01

Decide

Architecture, tech stack, module boundaries and interfaces. I settle these before any code is generated, because they are what make or break a codebase.

02

Delegate

Coding agents (Claude Code, Codex, Gemini) implement to that spec. They are connected through MCP to the tools the team already uses: Jira tickets, Figma designs, GitHub and Firebase.

03

Review

Line by line. I check which libraries the agents reached for, correct wrong turns, and restructure code where it needs it.

04

Ship

Tests, CI/CD, store release and production monitoring. The same release process I have followed for twelve years, reached sooner.

One codebase, both platforms

Kotlin Multiplatform keeps business logic, networking and the data layer in one place and ships it to Android and iOS. Compose Multiplatform can share the UI as well, where that makes sense. I have shipped iOS features myself, so I have a feel for where the shared code should stop.

Beyond the app

With agents doing the typing, I can also pick up the pieces around a mobile app: backend endpoints, a small web tool, build and release automation. Twelve years of production work is what keeps that code honest.
